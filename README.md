# দ্বীনি দোয়া ও আমল রিমাইন্ডার (Deeni Amal & Prayer Reminder App) 🌙

একটি আধুনিক, ১০০% অফলাইন উপযোগী এবং প্রামাণ্য সহীহ হাদিসভিত্তিক ইসলামিক আমল ও দোয়া রিমাইন্ডার মোবাইল PWA অ্যাপ।

## 🌟 বৈশিষ্ট্যসমূহ (Features)
- 🕌 **পাঁচ ওয়াক্ত ও তাহাজ্জুদ নামাজের পরের আমল:** ফজর, যোহর, আসর, মাগরিব, ইশা ও তাহাজ্জুদ নামাজের সালাম ফেরানোর পর রাসুলুল্লাহ (ﷺ) এর নির্দেশিত সুনির্দিষ্ট সুন্নাত আমল।
- 🛡️ **গুনাহ মাফের বিশেষ আমল:** সহীহ বুখারী ও মুসলিমের প্রামাণ্য হাদিসের আলোকে ১০০ বার সুবহানাল্লাহি ওয়া বিহামদিহি, সাইয়্যিদুল ইস্তিগফার ইত্যাদি।
- 🌅 **সকাল ও সন্ধ্যার মাসনূন জিকির:** আয়াতুল কুরসী, তিন কুল (ইখলাস, ফালাক, নাস) এবং সকাল-সন্ধ্যার প্রামাণ্য হিফাযতের দোয়া।
- 📿 **ইন্টারেক্টিভ ডিজিটাল তাসবীহ:** হ্যাপটিক ভাইব্রেশন ও রিয়েল-টাইম কাউন্টারসহ পূর্ণাঙ্গ তাসবীহ।
- 📖 **সহীহ হাদিসের সনদ ও দলিল ভিউয়ার:** প্রতিটি দোয়ার জন্য বুখারী, মুসলিম, আবু দাউদ, তিরমিযী ও নাসাঈর স্পষ্ট হাদিস নম্বর ও বাংলা অর্থ।
- 📱 **মোবাইল PWA ও অফলাইন সাপোর্ট:** যেকোনো ফোনে (Brave, Chrome, Safari) সরাসরি ইনস্টল করে ইন্টারনেট ছাড়াও সম্পূর্ণ কাজ করে।

## 🚀 টেক স্ট্যাক (Tech Stack)
- React 18 + Vite
- TypeScript
- Tailwind CSS
- Lucide React
- Service Worker & PWA Manifest
